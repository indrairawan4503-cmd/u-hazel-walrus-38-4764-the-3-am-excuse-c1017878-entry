The 3 AM Excuse — the hardware wallet's nightly seed-word count: every night at 3 AM it counts its twelve seed words, in order, twice, and your transaction just made it lose count. Back to one. Come back at dawn.

## Run it

```sh
mkdir -p /output && python3 main.py
```

Writes the entry line to `/output/entry.txt` (and a repo-root copy for local inspection).
